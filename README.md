# MBCI — Markinfo Brand Core Indicator · 웹 배포판

버전 **v2.11.0** · 빌드 **2026-09-29** · 마크인포

정적 파일만으로 동작합니다. 서버 프로그램, 데이터베이스, 빌드 도구가 필요하지 않습니다.

## 폴더 구조

```
index.html                     화면 마크업 (진단 · 결과 · 관리자)
version.json                   버전 정보
site.webmanifest               홈 화면 추가용 앱 정보
.htaccess                      캐시 설정 (Apache 계열에서만 사용)
assets/
  css/app.css                  스타일시트
  js/app.js                    애플리케이션 로직
  js/jszip.min.js              웹 업로드용 폴더 내보내기(.zip)에 쓰는 라이브러리 (오프라인에서도 동작)
  data/bsm-data.js             데이터 (글꼴 561종 · 스타일 16유형 · 목업 11개)
  img/brand/                   로고 · 파비콘(ico · png · apple-touch)
  img/mockups/                 목업 이미지
README.md
```

**폴더 구조를 바꾸면 이미지와 데이터를 찾지 못합니다.** 통째로 그대로 올려 주세요.

## 업로드 방법

- **일반 웹호스팅 · 카페24 · 가비아** — FTP로 `public_html`(또는 `www`) 아래에 폴더 내용을 그대로 업로드
- **Netlify · Vercel** — 이 폴더를 드래그 앤 드롭
- **GitHub Pages** — 저장소에 커밋 후 Pages 활성화
- **하위 경로 배포** — 모든 경로가 상대경로이므로 `example.com/bsm/` 같은 하위 폴더에서도 그대로 동작합니다

## 로컬에서 미리 보기

`index.html`을 두 번 클릭해서 열면 브라우저 보안 정책 때문에 **목업 합성과 내보내기(PNG·JPG·SVG)가 막힙니다.** 목업 이미지가 별도 파일이라 캔버스가 잠기기 때문입니다. 이때는 화면 아래에 빨간 안내 띠가 나타납니다.

폴더에서 아래 명령을 실행하고 `http://localhost:8080` 으로 접속하세요.

```
python3 -m http.server 8080
```

웹에 업로드한 뒤에는 이 제약이 없습니다.

## 데이터 수정 (관리자)

주소 끝에 `#admin` 을 붙이면 관리자 화면이 열립니다. 예: `example.com/#admin`

정적 호스팅이라 브라우저가 서버 파일을 직접 고칠 수 없습니다. 다음 순서로 반영합니다.

1. 관리자에서 글꼴 분류, 색상 기준, 목업 등을 수정합니다
2. 상단 **「데이터 파일 내보내기」** → `bsm-data.js` 가 내려받아집니다
3. 그 파일을 서버의 `assets/data/bsm-data.js` 위에 덮어씁니다
4. 새로고침하면 반영됩니다

내려받은 파일을 다시 화면으로 되돌리려면 **「데이터 불러오기」** 를 쓰면 됩니다.
내보낼 때마다 패치 버전이 1씩 올라갑니다 (v0.16.0 → 0.16.1 → 0.16.2 …).

> **주의** 내보내기를 하지 않고 창을 닫으면 변경 내용이 사라집니다. 화면을 벗어나려 하면 브라우저가 경고를 띄웁니다.

## 알아두실 점

- **글꼴** 웹폰트를 외부 CDN에서 불러옵니다. 인터넷이 막힌 환경에서는 기본 글꼴로 보이며, 이때 자동 검사는 멀쩡한 글꼴을 오류로 찍지 않도록 스스로 멈춥니다.
- **업로드 로고** 사용자가 결과 화면에서 올린 로고는 브라우저 안에서만 쓰이며 서버로 전송되거나 저장되지 않습니다. 새로고침하면 사라집니다.
- **SVG 내보내기** 「로고 윤곽선」은 글자를 패스로 변환하므로 글꼴이 없는 컴퓨터에서도 같은 모양으로 열립니다. 간판·시트 커팅용으로 이것을 쓰세요. 사용자가 올린 비트맵 로고는 완전한 벡터로 바뀌지 않습니다.
- **캐시** 데이터 파일을 교체했는데 화면이 그대로면 강력 새로고침(Ctrl+Shift+R)을 하거나, `index.html` 안의 스크립트 주소 끝에 `?v=0.18.1` 처럼 버전을 붙이세요.

## 버전 기록

- **문항을 12개→최대 20개까지 확장 가능** — 관리자 「질문 관리」에 「＋ 문항 추가」·「문항 삭제」 버튼을 추가했습니다. 새 문항은 내용을 채우기 전까지 비활성 상태로 시작해 실수로 빈 문항이 노출되지 않습니다. 삭제는 축당 최소 1개, 전체 최소 8개를 유지합니다. 인디케이터 퍼센트는 두 극의 점수 비율로 계산되므로 문항 수가 달라져도 0~100% 안에서 자동으로 맞춰집니다
- **채점 방식 변경**: 문항당 1점(기존 2점)
- 질문의 「둘 다 애매해요」 선택지를 기본적으로 껐습니다(관리자에서 다시 켤 수 있습니다)
- **[버그 수정] 결과 게이지 바 방향** — E 성향이면 왼쪽부터, I 성향이면 오른쪽부터 채워지도록 수정. 50% 중앙 기준선 삭제
- **질문 이미지를 완전한 선택 사항으로 변경** — 이미지가 없는 보기는 빈 이미지 틀 없이 문구만 표시됩니다
- 관리자에 **「메인 페이지」 편집 탭 신설(첫 번째 탭)** — 작은 안내 문구·메인 타이틀·서브 카피·배경색을 실시간 미리보기와 함께 수정할 수 있습니다
- **「상담용 페이지」 신설** — 관리자 상단의 「🎚 상담용 페이지」 링크(새 탭)로 열리며, 질문에 답하는 대신 4개 축을 슬라이더로 직접 조절해 원하는 Core ID를 즉시 만들어보고 색상·글꼴·목업까지 미리 볼 수 있습니다. 브랜드 이름·업종도 함께 입력할 수 있습니다
- **결과 이미지 다운로드** 버튼 추가 — 인디케이터와 결과 설명만 담은 PNG로 저장됩니다(목업·글꼴 목록 등은 제외)
- 서체 분류 간소화: **픽셀체를 장식체로 통합, 코딩체 삭제**(고딕으로 이전)
- 색상 조합의 「다른 조합 보기」가 간헐적으로 응답하지 않던 부분과 모바일에서 색상 조정·고정이 작동하지 않는 문제를 점검했습니다(재현 실패 항목은 README 하단 참고)
- 메인 페이지 업종 선택 옆 설명 문구 삭제
- 모바일 결과 인디케이터에 **접기/펼치기 버튼** 추가 — 기본은 접힌 상태로 코드·Core ID만 보이고, 버튼을 누르면 펼쳐집니다(데스크톱은 항상 펼침)
- 관리자 모바일 경고 배너의 줄바꿈·여백 정리

**참고**: 색상 팔레트의 모바일 조작(9번)과 「다른 조합 보기」 간헐적 미동작(10번), 관리자 내 NS/FT 순서(11번)는 에뮬레이션 환경에서 재현하지 못했습니다. 실기기에서 재현되면 구체적인 상황(기종/브라우저/조작 순서)을 알려주시면 다시 살펴보겠습니다.

### v2.10.0 (2026-09-29) — 결과 인디케이터 정리, 다른 코어 그리드, 색상 조합 간소화

- **[버그 수정] 결과 인디케이터에서 작은 숫자에 하이라이트가 붙던 문제** — 하이라이트가 "선택된 코드 글자"를 따라가던 기존 방식 때문에, Core Weight 점수가 낮은 축에서도(예: 40%) 그 쪽이 강조 표시되는 경우가 있었습니다. 이제 게이지의 퍼센트·강조 표시는 두 극의 점수 비율로 계산해 **항상 더 큰 숫자 쪽이 강조**됩니다. 4,096가지 응답 조합 전수 검증 결과 불일치 0건. (Core ID 상단의 다이아몬드 표기는 채점 가이드대로 절대 점수를 그대로 씁니다 — 이 둘은 원래 다른 값입니다)
- 「다시 테스트하기」를 누르면 **결과가 초기화된다는 확인 메시지**가 뜨고, 취소하면 그대로 유지됩니다
- 「다시 테스트하기」·「다른 코어 보기」 버튼 사이 간격 확보
- **「다른 코어 보기」를 누르면 게이지 자리가 16개 코어 버튼 그리드로 바뀝니다.** 버튼에는 코드와 이름이 함께 표시되고, 고르면 오른쪽 결과만 바뀌고 왼쪽은 실제 테스트 게이지로 돌아옵니다. 버튼 라벨은 미리보는 동안 **「돌아가기」**로 바뀌고, 누르면 완전히 원래 결과로 복귀합니다
- 색상 조합 이름 간소화, **세퍼레이션 삭제**(톤온톤·톤인톤·포인트 3종만 남김). 세퍼레이션을 기본값으로 쓰던 3개 스타일은 톤인톤으로 재배정
- 브랜드 목업의 「내 로고 올리기」 기본 설명 문구 삭제
- 관리자 모바일 경고 메시지의 줄바꿈·여백 정리
- **폰트 형태에서 "보류" 삭제** — 원래 "판단이 어려운 폰트"를 위한 기능은 별도의 「분류 보류」 체크박스로 이미 있었는데, 지난 업데이트에서 실수로 같은 이름의 "형태" 옵션을 추가로 만들어 두 기능이 겹쳐 있었습니다. 실제로 이 형태를 쓰는 폰트는 없었어서 데이터 손실 없이 정리했습니다

### v2.9.0 (2026-09-29) — 결과 화면 레이아웃 정리, 다른 코어 미리보기, 잔여 분류 정리

- **브랜드 목업 도구줄을 한 줄로 통합** — 업종 선택·다시 그리기·로고 올리기·내보내기가 따로 놀며 내보내기 오른쪽에 큰 여백이 남던 문제를 정리. 모바일에서는 세로로 쌓이도록 유지
- **[버그 수정] 결과 화면이 특정 너비(약 960~1180px)에서 심하게 눌리던 문제** — 2단 레이아웃이 풀리는 기준을 960px에서 1180px로 넓혀서, 왼쪽 고정폭(396px) 때문에 오른쪽 글꼴 캐러셀이 비정상적으로 좁아지던 구간을 없앴습니다. 캐러셀 화살표 뒤 흰 그라디언트가 어긋나 보이던 것도 같은 원인이라 함께 해결됩니다
- 글꼴 카드의 형태·웨이트·인상 태그가 절대 줄바꿈되지 않도록 고정
- 결과 게이지 아래 **「다른 코어 보기」** 추가 — 이름·업종 선택은 그대로 둔 채 다른 코어의 색상·글꼴·목업을 미리 볼 수 있고, 「내 결과로 돌아가기」로 실제 테스트 결과로 복귀할 수 있습니다
- 결과 게이지에서 이긴 쪽 영문 라벨을 **굵게 + 초록색**으로 강조. 가운데 정렬이 맞지 않던 E/I·N/S 같은 코드 표기는 삭제
- **SNS 프로필**을 업종 선택 목록에서 빼고, 업종과 무관하게 항상 고를 수 있는 **목업 라이브러리 항목**으로 이동
- 관리자 「로고 이미지」 탭의 스타일 선택 줄에 **이전 · 다음** 버튼 추가 — 여러 코어를 순서대로 넘나들며 비교·수정할 수 있습니다
- 글꼴 형태 분류에서 **탈네모·캘리폰트·영문이 실제로는 제거되지 않고 남아있던 문제**를 완전히 해결 — 데이터가 아니라 `index.html`에 굳이 박혀 있던 옛 옵션 목록(폰트 리스트 필터, 알고리즘 탭, 폰트 분류 카드) 세 곳이 원인이었습니다. 이번엔 값이 있어도 항상 최신 분류로 다시 채우도록 고쳐서 같은 문제가 재발하지 않습니다

- 푸터에서 "업로드한 이미지는…" 안내 문구 삭제

### v0.19.1 (2026-09-05) — 긴급 수정
